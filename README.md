# Projeto: Rede Corporativa — TechBrasil Ltda

Esse repositório documenta um projeto prático de infraestrutura de redes simulado no **Cisco Packet Tracer**, com foco no dia a dia real de um profissional de Suporte N1/N2 e Analista de Infraestrutura de TI.

A ideia é simular, fase por fase, situações reais que acontecem dentro de uma empresa: configuração de equipamentos, organização da rede, separação por departamentos, servidores internos, troubleshooting e muito mais.

> **Empresa fictícia:** TechBrasil Ltda — escritório com aproximadamente 20 funcionários.
